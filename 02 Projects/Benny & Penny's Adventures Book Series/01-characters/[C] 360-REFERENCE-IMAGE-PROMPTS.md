# 360° Reference Image Prompts — Copy/Paste for Copilot

One prompt per character, built from the reconciled locks (post 2026-08-24 update). Use these to generate the new confirmed 360° reference sheets before locking each character in for Book 1.

## How to use
1. **Attach the artist's approved reference image for that character first** (see "Attach" line in each prompt below), then paste the prompt text.
2. Generate **one character at a time** — don't mix characters in one request.
3. When you get results back, check them against the DO-NOT-DRIFT list in that character's `*-CHARACTER-LOCK.md` file before treating anything as final.
4. Send the approved images back and I'll drop them into `_reference-images/`, update each lock's reference registry, and mark the new 360 sheet as the gold-standard reference.

> **Lesson learned (2026-08-24):** generic "same pose across FRONT/SIDE/BACK/¾" instructions leave the model to guess what each angle actually looks like — Copilot's first Benny Bear back view rotated his feet to face the camera instead of tucking them away like a real plush toy viewed from behind. Every prompt below now spells out what each individual view must (and must not) show.
